# HAVAL — дизайн-токены проекта

Единый источник истины для всех комплектов проекта `haval/`. Правила использования — раздел 0 `.claude/agents/cefalot-widget-developer.md`: этот блок копируется **дословно** в начало `:root, :host { ... }` каждого `desktop.css`/`mobile.css` любого нового или изменяемого комплекта. Ничего не изобретай заново на глаз в конкретной форме.

## Статус

- Токен-набор — `--cf-*` (не `--hv-*`). Это решено пользователем 2026-08-25: часть комплектов проекта успела задрейфовать на другой, менее полный набор переменных (`--hv-*`, акцент `#3FBFAE`, плоское скругление `2px` без шкалы) — `--cf-*` выбран как канонический, потому что уже используется в бóльшей части проекта (меню, экран «Спасибо») и полнее (hover/active-состояния акцента, control-h, tap-target, moción-токены есть только в нём).
- Этот документ фиксирует **только сам набор токенов**. Приведение уже существующих `--hv-*`-комплектов (`2 - тест-драйв`, `3 - тест-драйв`, `5 - спецпредложения`) к этому набору — отдельная, ещё не выполненная задача (сознательно оставлена на потом по решению пользователя от 2026-08-25).

## Шрифт бренда

В корне проекта уже лежат три файла шрифта бренда: `Haval-Light.woff2`, `Haval-Regular.woff2`, `Haval-Medium.woff2`. Ни один существующий комплект их пока не подключает (везде используется системный fallback-стек).

Подключение — по образцу уже работающего паттерна в `tenet/0 - меню/*.css` (тот же приём для другого проекта на этой же платформе): `@font-face` со ссылкой через `{{asset:key}}` — это единственное разрешённое исключение из запрета на внешние `url(...)` в CSS (раздел 4 агентского файла).

```css
@font-face {
  font-family: "Haval";
  src: url("{{asset:haval-light}}") format("woff2");
  font-weight: 300;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Haval";
  src: url("{{asset:haval-regular}}") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Haval";
  src: url("{{asset:haval-medium}}") format("woff2");
  font-weight: 500;
  font-style: normal;
  font-display: swap;
}
```

`--cf-font` в каноническом блоке выше уже ссылается на `"Haval"` первым в стеке, с безопасным fallback после него.

**Не подтверждено, требует проверки перед использованием:** ключи `haval-light` / `haval-regular` / `haval-medium` — это предположение по аналогии с `tenet`, а не проверенные значения. Реальный `{{asset:key}}` присваивается при загрузке файла шрифта в библиотеку ассетов кабинета Cefalot — нужно либо загрузить файлы и посмотреть, какой ключ выдаёт кабинет, либо свериться с кнопкой быстрой вставки «Шрифт» в редакторе (раздел «Как заливать готовые файлы в кабинет Cefalot» агентского файла). Не полагайся на ключи выше как на готовые — подставь реальные перед заливкой в продакшн.

## Правила применения

1. При создании/правке любого комплекта в `haval/` — канонический блок `:root, :host {...}` копируется в начало `desktop.css` и `mobile.css` без изменений.
2. Локальные, специфичные для одного комплекта переменные (как `--hv-accent-tint` было в старом `5 - спецпредложения`) заводятся отдельно, с комментарием, что это локальный токен именно этого комплекта — не смешивать с базовым набором.
3. Если значение в этом документе меняется задним числом — обновить синхронно все уже существующие комплекты проекта, не оставлять часть форм на старом значении.
