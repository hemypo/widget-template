# Виджет TENET — 8 комплектов по 5 файлов

Дизайн-язык снят с **tenet.ru** (шрифт TENET Sans, ink `#3E3A39`, бордер/CTA `#D8CEC5`,
акцент `#C30D23`, радиус полей 12 px, высота поля 56 px, лейблы 11 px uppercase / letter-spacing 1 px).
Раскладка окна — по скриншоту: чипы, крупная CTA, плитки с иконками.

## Состав

| # | Папка | Форма / состояние | ID для `data-widget-form` |
|---|-------|-------------------|---------------------------|
| 1 | `01-main-menu` | Главный экран (разводящая) | `FORM_MAIN` |
| 2 | `02-callback` | Заказать звонок | `FORM_CALLBACK` |
| 3 | `03-test-drive` | Запись на тест-драйв | `FORM_TEST_DRIVE` |
| 4 | `04-offers` | Спецпредложения | `FORM_OFFERS` |
| 5 | `05-trade-in-catalog` | Обменять на новый (каталог трейд-ин, 5 подшагов) | `FORM_TRADE_IN` |
| 6 | `06-credit` | Рассчитать кредит | `FORM_CREDIT` |
| 7 | `07-leasing` | Оформить лизинг | `FORM_LEASING` |
| 8 | `08-success` | Экран «Спасибо» (общий для всех форм) | `FORM_SUCCESS` |

В каждой папке ровно 5 файлов:

```
<slug>--markup-desktop.html    разметка, десктоп
<slug>--markup-mobile.html     разметка, мобильная
<slug>--styles-common.css      токены + общие правила
<slug>--styles-desktop.css     только десктопные отличия
<slug>--styles-mobile.css      только мобильные отличия
```

## Что нужно сделать при заливке

1. **Создать формы** с ID из таблицы выше. Если ID в вашей админке другие — поправьте значения
   `data-widget-form` в `01-main-menu/*.html` (6 чипов + плитка «Расчёт трейд-ин») и в
   `08-success/*.html` (кнопка «В меню»).
2. **Настроить редирект после отправки** на `FORM_SUCCESS` — комплект 8 общий для всех форм.
3. **Загрузить шрифты** через кнопки медиа платформы и подставить свои ключи в `@font-face`
   каждого `--styles-common.css`:
   `{{asset:tenet-sans-regular}}`, `{{asset:tenet-sans-medium}}`, `{{asset:tenet-sans-semiexpanded-bold}}`.
   Если ассетов нет — блок `@font-face` можно удалить, останется системный fallback (Arial).
4. **Размеры и положение окон не заданы** — ни `width`, ни `position`, ни `max-width`
   ни на `.cefalot-form-custom-template-content`, ни на `.tw--desktop` / `.tw--mobile`.
   Задавайте их в редакторе.

## Соответствие ограничениям платформы

Прогнан автоматический валидатор (`build/validate.py`) — нарушений нет:

- нет `script`, `style`, `iframe`, `object`, `embed`, `template`, `link`, `meta`, `base`;
- нет тега `<form>` — всё на `div` + `data-widget-*`;
- нет обработчиков событий и инлайновых `style`;
- нет внешних `url(...)` в CSS и SVG — только `{{asset:key}}`;
- нет хардкодных URL картинок, все иконки — безопасный inline SVG
  (`svg / path / circle / rect / line / polyline / polygon / g`);
- все поля имеют `name` и `data-widget-field` (в каталоге — `data-widget-catalog-field`);
- переменные объявлены в `:root, :host`, контент обёрнут в `.cefalot-form-custom-template-content`.

**Про `<label>`:** тега `label` нет в белом списке разрешённых тегов, поэтому подписи сделаны
через `<span class="tw-label" id="...">` + `aria-labelledby` на поле. Доступность сохраняется,
санитайзер не режет.

## Каталог трейд-ин (комплект 5)

Подшаги: `brand` → `model` → `state` → `new` → `contacts`.

- контейнеры — `data-widget-catalog-substep="…"`, подписи — `data-widget-catalog-substep-label`;
- поля — `data-widget-catalog-field`;
- навигация — `data-widget-catalog-next` / `-back`, прямые переходы из левой рельсы —
  `data-widget-catalog-go="brand|model|state|new|contacts"`;
- отправка — `data-widget-submit` на последнем подшаге.

На десктопе рельса — тёмная колонка слева (как в калькуляторе на tenet.ru), на мобайле —
горизонтальная лента с прокруткой. Активный подшаг подсвечивается красным номером через
`.tw-rail__item[aria-current]` или `.is-active` — подставьте класс/атрибут, который вешает платформа.

## Ограничение, о котором стоит знать

**Живой расчёт кредита/трейд-ин на клиенте невозможен** — платформа запрещает `script`.
Поэтому формы «Рассчитать кредит» и трейд-ин собирают параметры (взнос, срок, программа,
пробег, год) и показывают честный блок «Рассчитает менеджер», а не фейковую цифру.
Если нужен живой калькулятор — это делается на стороне платформы/бэкенда,
разметка под результат уже есть: блок `.tw-summary` с `.tw-summary__val`.

## UX-решения

- 16 px размер шрифта у полей — iOS не зумит экран при фокусе.
- Все тач-цели ≥ 44 × 44 px, чекбоксы 24 px внутри строки высотой 44 px.
- Видимые лейблы (не placeholder-only), звёздочка обязательности красная `#C30D23`.
- Фокус: рамка + мягкое кольцо, `:focus-visible` нигде не снят.
- Переходы 200–300 ms, есть блок `@media (prefers-reduced-motion: reduce)`.
- Мобильные комплекты — одна колонка, CTA на всю ширину, вторичное действие под ней.
