# JELAND — дизайн-токены проекта

Единый источник истины для всех комплектов проекта `jeland/`. Правила использования — `.claude/agents/cefalot-widget-developer-v4.md`, раздел 0: этот блок копируется **дословно** в начало `desktop.css`/`mobile.css` каждого комплекта (для многошаговых форм — один `desktop.css`/`mobile.css` на весь комплект). Ничего не изобретать заново «на глаз» в конкретной форме.

## Статус (обновлено 2026-09-02)

- Цвета и типографика взяты напрямую с официального сайта бренда `jelandrus.ru` (computed styles реальных элементов — шапка, кнопки, заголовки), не придуманы на глаз.
- **Акцент** — стальной сине-серый `#3A83A3` (`rgb(58, 131, 163)`, реальный цвет CTA-кнопки "Позвоните мне" на сайте). Hover/active — не отдельные токены сайта (там только один тон), затемнены вручную по той же методике, что и `haval`/`changan`.
- **Шрифт — только `Geologica`, для заголовков и текста/интерфейса (вес 700/500 для заголовков, 400 для текста).** По решению пользователя используется единый шрифт для heading и body — реальный сайт использует `Involve` в кнопках/заголовках, но проект сознательно на него не переходит. **Файлов `.woff2` в проекте пока нет** — до появления файла в токен-блоке используется системный fallback-стек, `@font-face` в комплектах не подключается вообще. Как только пользователь положит `.woff2` файл в `jeland/` — добавить `@font-face` по образцу `changan`/`haval` (раздел 0b агентского файла) и обновить этот документ.
- **Радиусы — плоские, `0` везде (отменено решение от 2026-09-02 о скругленной шкале 4/8/16/32px).** Пользователь указал, что кнопки и скругления не соответствуют официальному сайту — проверено заново computed-style реального сайта: `border-radius: 0px` без исключений на кнопках, полях ввода, чекбоксах, карточках, футере, шапке. Виджет теперь копирует это буквально: все `--cf-r-*` токены равны `0`.
- **Кнопки — фирменный срез угла (chamfer), а не скругление.** Единственный акцентный элемент формы у реального сайта — не border-radius, а `clip-path`-срез нижнего правого угла на заливных (`btn_primary`) кнопках: `clip-path: polygon(0 0, 100% 0, 100% calc(100% - 15px), calc(100% - 16px) 100%, 0 100%)` при высоте кнопки 56px (подтверждено скриншотом кнопки "Узнать больше" с сайта и повторной сверкой computed style). Второстепенные/прозрачные кнопки (`btn_arrow`, quiet) среза не имеют — остаются простым плоским прямоугольником. Смасштабировано под `--cf-control-h: 52px` как `--cf-chamfer: 14px`, применяется через `--cf-chamfer` в каждом комплекте только к `.cefalot-btn--primary`.
- **Тёмная тема сайта не переносится на карточку виджета** — виджет остаётся на белой поверхности (`--cf-surface: #FFFFFF`), как у `haval`/`changan`; тёмный `#181D21` сайта используется только как `--cf-ink` (цвет текста), не как фон карточки.
- **Обновлено (2026-09-03)** — `--cf-accent-glow` (`rgba(58, 131, 163, 0.35)`) добавлен в канонический блок ниже: по распоряжению пользователя стиль виджета переводится на «яркий и привлекательный», зеркалируя изменение, уже применённое в `changan` (см. `changan/DESIGN-TOKENS.md`) — градиентные заливки, свечение (glow-тени) вокруг акцентных элементов, крупные тени у кнопок, жирнее шрифты, градиентный заголовок (текст-клип), редизайн чекбокса/селекта. Для `jeland` паттерн переведён на собственные токены проекта — акцент `#3A83A3` вместо оранжевого, плоские (`0`) скругления везде без исключений, срез угла (`--cf-chamfer`) на `.cefalot-btn--primary` сохранён и не затронут (просто применяется поверх нового градиентного фона кнопки). Мобильный hero-паттерн «1 - обратный звонок» (фото + scrim + белый текст поверх) — собственное, ранее подтверждённое решение проекта, сохранено без изменений, просто получило усиленную (glow) стилистику эйбрау/заголовка в тон общему обновлению. **Синхронизировано (весь проект):** `0 - меню` (compact + expanded, оба вьюпорта), `1 - обратный звонок`, `2 - трейд-ин`, `3 - тест-драйв`, `4 - расчет кредита`, `5 - спецпредложения`, `00 - спасибо` — все bundles на новом «ярком» визуальном языке.

Для `0 - меню` (структура уникальна для проекта — см. ниже) стиль адаптирован под её собственные элементы, которых нет в формах: кнопка-лаунчер (`compact.*`) получила градиентную заливку `--cf-accent → --cf-accent-hover` вместо плоского `--cf-accent`, статический glow (`--cf-accent-glow`) встроен в существующую pulse-анимацию и в тень плашки с перечислением форм; в `expanded.*` шапка (desktop) и строки меню при hover/active тоже переведены на градиент + glow-тень, сама строчная manifest-структура (не сетка карточек) не менялась. Для `5 - спецпредложения` карточки предложений (шаг 1) получили обработку по аналогии с карточками подшагов `2 - трейд-ин`: акцентная рамка + мягкий градиентный тинт фона + glow-тень при выборе (`:checked`), градиентная заливка кружка-индикатора и чекмарки.

## Шрифт бренда — пока не подключается

Файла `Geologica-*.woff2` в `jeland/` нет. Порядок подключения, когда он появится (сразу после блока `:root, :host`, см. раздел 0b агентского файла):

```css
@font-face { font-family: "Geologica"; src: url("{{asset:jeland-font-body}}") format("woff2"); font-weight: 400; font-display: swap; }
@font-face { font-family: "Geologica"; src: url("{{asset:jeland-font-heading}}") format("woff2"); font-weight: 700; font-display: swap; }
.cefalot-form-custom-template-root { font-family: "Geologica", system-ui, sans-serif; }
```

До этого момента `--cf-font`/`--cf-font-heading` используют только fallback-стек — форма не сломается, просто без брендового начертания.

## Многошаговые формы (desktop-N / mobile-N)

Как в `changan`/`haval` (см. агентский файл, подраздел «Многошаговые формы»): несколько основных шагов = несколько полных `desktop-N.html`/`mobile-N.html`, один общий `desktop.css`/`mobile.css` на комплект. Список форм проекта зеркалит `changan`/`haval` 1:1 по составу (распоряжение пользователя «список форм такой же»):

- `1 - обратный звонок` — одношаговая (hero-layout).
- `2 - трейд-ин` — одношаговый каталог (`data-widget-catalog-*`, карточки-подшаги без рельсы — актуальная структура `changan`/`haval`).
- `3 - тест-драйв` — одношаговая (hero-layout + select модели).
- `4 - расчет кредита` — одношаговая (hero-layout + select модели).
- `5 - спецпредложения` — многошаговая, 2 шага (карточки-предложения на шаге 1, контакты на шаге 2).

`0 - меню` — **expanded уникален для этого проекта** (не копия сетки карточек `changan`/`haval`, отдельное решение, см. сам комплект и его внутренние комментарии).

## Правила применения

1. При создании любого комплекта в `jeland/` — канонический блок `:root, :host {...}` копируется в начало `desktop.css`/`mobile.css` без изменений.
2. Локальные, специфичные для одного комплекта переменные — отдельным блоком с комментарием.
3. Если значение меняется задним числом (например, когда появятся файлы шрифта) — обновить синхронно все уже существующие комплекты проекта.
4. **`.cefalot-btn--primary` обязан получать срез угла**, помимо обычных правил `.cefalot-btn`:
   ```css
   .cefalot-btn--primary {
     clip-path: polygon(0 0, 100% 0, 100% calc(100% - var(--cf-chamfer)), calc(100% - var(--cf-chamfer)) 100%, 0 100%);
   }
   ```
   Второстепенные кнопки (`.cefalot-btn--quiet` и любые прозрачные/outline-кнопки) среза не получают — остаются простым прямоугольником без `border-radius` и без `clip-path`.
