# JELAND — дизайн-токены проекта

Единый источник истины для всех комплектов проекта `jeland/`. Правила использования — `.claude/agents/cefalot-widget-developer-updated-v3.md`, раздел 0: этот блок копируется **дословно** в начало `desktop.css`/`mobile.css` каждого комплекта (для многошаговых форм — один `desktop.css`/`mobile.css` на весь комплект). Ничего не изобретать заново «на глаз» в конкретной форме.

## Статус (создано 2026-09-01)

- Цвета и типографика взяты напрямую с официального сайта бренда `jelandrus.ru` (computed styles реальных элементов — шапка, кнопки, заголовки), не придуманы на глаз.
- **Акцент** — стальной сине-серый `#3A83A3` (`rgb(58, 131, 163)`, реальный цвет CTA-кнопки "Позвоните мне" на сайте). Hover/active — не отдельные токены сайта (там только один тон), затемнены вручную по той же методике, что и `haval`/`changan`.
- **Шрифты бренда — `Involve` (заголовки, вес 700/500) и `Geologica` (текст/интерфейс, вес 400).** Оба взяты из `font-family` реальных элементов сайта (`getComputedStyle`). **Файлов `.woff2` этих шрифтов в проекте пока нет** — в отличие от `changan`, куда пользователь уже положил скачанные файлы, для `jeland` этого шага не было. До появления файлов в токен-блоке используется системный fallback-стек, `@font-face` в комплектах пока не подключается вообще (не «плейсхолдер с TODO», как в `changan`, а полное отсутствие блока — подключать нечего, файлов нет физически). Как только пользователь положит `.woff2` файлы в `jeland/` — добавить `@font-face` по образцу `changan`/`haval` (раздел 0b агентского файла) и обновить этот документ.
- **Радиусы — плоские, `0px` везде.** Реальный сайт JELAND не скругляет вообще ничего (`border-radius: 0px` подтверждено на кнопках, ссылках, header) — это осознанная часть острой, геометричной айдентики бренда (угловатый логотип JELAND). В отличие от `changan` (мягкие скругления) и `haval` (5px), здесь острые прямые углы — фирменный стиль, не упрощение.
- **Тёмная тема сайта не переносится на карточку виджета** — виджет остаётся на белой поверхности (`--cf-surface: #FFFFFF`), как у `haval`/`changan`; тёмный `#181D21` сайта используется только как `--cf-ink` (цвет текста), не как фон карточки.

## Шрифт бренда — пока не подключается

Файлов `Involve-*.woff2`/`Geologica-*.woff2` в `jeland/` нет. Порядок подключения, когда они появятся (сразу после блока `:root, :host`, см. раздел 0b агентского файла):

```css
@font-face { font-family: "Involve"; src: url("{{asset:jeland-font-heading}}") format("woff2"); font-weight: 700; font-display: swap; }
@font-face { font-family: "Geologica"; src: url("{{asset:jeland-font-body}}") format("woff2"); font-weight: 400; font-display: swap; }
.cefalot-form-custom-template-root { font-family: "Geologica", system-ui, sans-serif; }
```

До этого момента `--cf-font`/`--cf-font-heading` используют только fallback-стек — форма не сломается, просто без брендового начертания.

## Многошаговые формы (desktop-N / mobile-N)

Как в `changan`/`haval` (см. агентский файл, подраздел «Многошаговые формы»): несколько основных шагов = несколько полных `desktop-N.html`/`mobile-N.html`, один общий `desktop.css`/`mobile.css` на комплект. Список форм проекта зеркалит `changan`/`haval` 1:1 по составу (распоряжение пользователя «список форм такой же»):

- `1 - обратный звонок` — одношаговая (hero-layout).
- `2 - трейд-ин` — одношаговый каталог (`data-widget-catalog-*`, карточки-подшаги без рельсы — актуальная структура `changan`/`haval`).
- `3 - тест-драйв` — одношаговая (hero-layout + select модели).
- `4 - расчет кредита` — одношаговая (hero-layout + select модели).
- `5 - спецпредложения` — многошаговая, 2 шага (карточки-предложения на шаге 1, контакты на шаге 2).

`0 - меню` — **expanded уникален для этого проекта** (не копия сетки карточек `changan`/`haval`, отдельное решение, см. сам комплект и его внутренние комментарии).

## Правила применения

1. При создании любого комплекта в `jeland/` — канонический блок `:root, :host {...}` копируется в начало `desktop.css`/`mobile.css` без изменений.
2. Локальные, специфичные для одного комплекта переменные — отдельным блоком с комментарием.
3. Если значение меняется задним числом (например, когда появятся файлы шрифта) — обновить синхронно все уже существующие комплекты проекта.
