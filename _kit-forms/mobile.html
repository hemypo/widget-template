5. Radio — видимый choice-grid (карточки)

Использовать когда варианты должны быть видны целиком сразу (например тип клиента, срок кредита). В каталоге трейд-ина применяется другой подход — см. _kit-catalog.

6. Radio — карточки offer-card (номер + заголовок + бейдж)

Использовать для выбора из списка предложений/акций, где у каждого варианта есть короткое заголовочное название и отдельная выгода/цифра, которую нужно выделить, но не так тяжеловесно, как .cefalot-eyebrow (сплошная заливка акцентом — предназначена для одного заголовочного лейбла формы/шага, не для повторяющегося списка бейджей — см. `changan/5 - спецпредложения`, где именно это было заменено). Бейдж `.cefalot-offer-card__badge` — мягкая пилюля (`--cf-accent-tint` фон, `--cf-accent-active` текст), без точки-маркера.
